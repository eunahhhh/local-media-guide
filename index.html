1
스크립트 파일 준비
run_all.sh 파일을 Script 폴더에 저장합니다
STEP 1
폴더 2개 생성 후 파일 다운로드

먼저 바탕화면에 매체정리 폴더와 Script 폴더를 새로 만들어주세요.

Finder에서 바탕화면 우클릭 → 새로운 폴더 → 이름 입력 (두 번 반복)

그 다음 아래 버튼을 눌러 두 파일을 다운로드한 뒤 각각 지정된 폴더에 넣어주세요.

⬇️  run_all.sh 다운로드 ⬇️  config.txt 다운로드
📁 바탕화면/ ├── 📁 Script/ │ └── run_all.sh ← Script 폴더 안에 넣기 └── 📁 매체정리/ └── config.txt ← 매체정리 폴더 안에 넣기
⚠️ config.txt는 담당 매체에 맞게 수정해서 써야 해요. ✨ 커스터마이징 탭에서 수정 방법을 확인하세요.
STEP 2
파일명 규칙 확인

파일을 매체정리 폴더에 넣으면 아래처럼 매체별로 자동 분류됩니다. 파일명에 매체사 이름이 포함되어야 자동 분류돼요.

✅ 분류되는 파일명 Meta_배너_v2.jpg google_영상광고.png Kakao_상품_최종.jpg TikTok_15s_소재.png
❌ 미분류로 남는 파일명 광고소재_v2.jpg 최종본_수정.png 배너_2차검토.jpg upload_230501.png
2
실행 권한 부여 (최초 1회)
macOS는 새 스크립트를 바로 실행할 수 없어서 권한을 먼저 줘야 합니다
STEP 3
터미널 열기

⌘ + Space 를 눌러 Spotlight를 열고 터미널을 검색 후 엔터

💡 이후 Automator 설정이 완료되면 터미널을 다시 쓸 일은 없어요. 이번 한 번만!
STEP 4
권한 부여 명령어 실행

터미널에 아래 명령어를 복사해서 붙여넣기 후 엔터를 누르세요.

# 실행 권한 부여 chmod +x ~/Desktop/Script/run_all.sh

아무 반응이 없으면 정상입니다. 에러가 없으면 성공!

⚠️ Script 폴더 위치가 다르면 경로를 맞게 바꿔주세요.
3
Automator 폴더 감시 설정
파일이 매체정리 폴더에 들어오면 자동으로 스크립트가 실행됩니다
STEP 5
Automator 열기

⌘ + Space → Automator 검색 → 엔터

STEP 6
문서 유형 — "폴더 적용 스크립트" 선택

새 문서 창이 열리면 폴더 적용 스크립트를 선택하고 "선택" 버튼을 클릭합니다.

Automator — 새 문서
▶️ 워크플로우
📁 폴더 적용 스크립트 ← 선택
🔔 캘린더 알림
STEP 7
감시할 폴더 지정

오른쪽 상단에 "폴더 동작 받기:" 드롭다운이 있습니다. 클릭 후 기타를 선택해서 바탕화면의 매체정리 폴더를 직접 선택하세요.

폴더 동작 편집기
📁  폴더 동작 받기:  매체정리  에 추가된 파일
← 동작을 여기에 드래그하거나 라이브러리에서 추가하세요
STEP 8
"셸 스크립트 실행" 동작 추가

왼쪽 검색창에 셸 스크립트 라고 입력 → 결과에서 "셸 스크립트 실행" 항목을 오른쪽 영역으로 더블클릭 또는 드래그해서 추가합니다.

폴더 동작 편집기
📁  폴더 동작 받기:  매체정리
💻
셸 스크립트 실행
유틸리티 › 셸 스크립트 실행
STEP 9
스크립트 명령어 입력

추가된 동작 안의 텍스트 입력창에 기존 내용을 모두 지우고 아래 명령어를 붙여넣습니다.

bash ~/Desktop/Script/run_all.sh
⚠️ Script 폴더 위치가 다르면 경로를 맞게 수정하세요.
STEP 10
저장하기

⌘ + S 를 눌러 저장합니다. 파일명은 매체정리_자동실행 으로 입력하세요.

✅ 저장하는 순간 폴더 감시가 자동으로 활성화됩니다. 앞으로는 Automator를 다시 열 필요가 없어요!

구조 안내
이제 스크립트를 직접 수정할 필요 없어요

매체정리 폴더 안에 있는 config.txt 파일은 매체 추가, 용량 설정을 아주 쉽게 할 수 있어요.

📁 매체정리/ ├── config.txt ← 여기만 수정! ├── run_all.sh ← 건드릴 필요 없음 ├── 📁 Meta/ ├── 📁 Naver/ └── 📁 기타/
💡 팀원마다 자신의 config.txt만 담당 매체에 맞게 바꾸면 돼요. run_all.sh는 모두 동일하게 공유해서 써요.
매체 추가
담당 매체 추가하기

config.txt를 텍스트 편집기로 열고 MEDIA= 줄에 담당 매체를 쉼표로 추가하면 돼요.

# 수정 전 MEDIA=Meta,Google,Kakao,Naver # 수정 후 — Moloco 추가 MEDIA=Meta,Google,Kakao,Naver,Moloco
⚠️ 파일명에 매체명이 포함되어야 자동 분류돼요. 예: Moloco_배너.jpg → Moloco 폴더로 이동
전체 용량
매체 전체 용량 제한 추가하기

특정 매체의 모든 파일에 동일한 용량을 적용하려면 아래 형식으로 한 줄 추가하면 돼요.

# 형식: 매체명:용량KB Kakao:500 # Kakao 전체 500KB 이하 Moloco:1024 # Moloco 전체 1MB 이하
사이즈별 용량
매체 내 사이즈별 용량 제한 추가하기

같은 매체 안에서도 사이즈마다 다른 용량을 적용하려면 아래 형식으로 추가하면 돼요.

# 형식: 매체명:사이즈:용량KB Naver:1200x628:500 # Naver 1200x628 → 500KB Naver:1250x560:250 # Naver 1250x560 → 250KB 블라인드:1200x628:100 # 블라인드 피드배너 → 100KB 블라인드:1250x560:200 # 블라인드 게시글배너 → 200KB
💡 파일명에 사이즈가 없으면 자동으로 건너뛰어요. 예: Naver_배너.jpg → 건너뜀 / Naver_1200x628_배너.jpg → 500KB 압축
예시
팀원별 config.txt 작성 예시

각자 담당 매체에 맞게 아래처럼 작성하면 돼요.

# ① 담당 매체 목록 MEDIA=Naver,블라인드,Kakao # ② 매체 전체 용량 제한 Kakao:500 # ③ 사이즈별 용량 제한 Naver:1200x628:500 Naver:1250x560:250 Naver:1200x1200:800 블라인드:1200x628:100 블라인드:1250x560:200
✅ 저장 후 파일을 매체정리 폴더에 넣으면 config.txt 설정대로 자동 분류 + 압축이 적용돼요!
