스크립트 파일 준비
run_all.sh 파일을 바탕화면에 저장합니다
STEP 1
공유받은 run_all.sh 파일을 바탕화면에 저장

아래 버튼을 눌러 run_all.sh 파일을 다운로드한 뒤 바탕화면으로 이동하세요.

⬇️  run_all.sh 다운로드
💡 파일 위치는 어디든 괜찮지만, 이 가이드는 바탕화면(Desktop)을 기준으로 설명합니다. 다른 곳에 저장했다면 이후 경로를 맞게 수정해야 해요.
STEP 2
매체정리 폴더 확인

바탕화면에 매체정리 폴더를 직접 만들어주세요. Automator가 이 폴더를 감시하려면 폴더가 미리 존재해야 합니다.

Finder에서 바탕화면 우클릭 → 새로운 폴더 → 이름을 매체정리 로 입력하면 됩니다.

파일을 넣으면 아래처럼 자동으로 분류됩니다.

📁 매체정리/ ├── 📁 Meta/ ├── 📁 Google/ ├── 📁 Kakao/ ← 500KB 초과 이미지 자동 압축 ├── 📁 Naver/ ├── 📁 Youtube/ ├── 📁 TikTok/ ├── 📁 Coupang/ └── 📁 기타/ ← 매체명 없는 파일
⚠️ 파일명에 매체사 이름이 포함되어야 자동 분류됩니다. 예: Meta_배너_230101.jpg
✅ 분류되는 파일명 Meta_배너_v2.jpg google_영상광고.png Kakao_상품_최종.jpg TikTok_15s_소재.png
❌ 기타로 이동되는 파일명 광고소재_v2.jpg 최종본_수정.png 배너_2차검토.jpg upload_230501.png

macOS는 새 스크립트를 바로 실행할 수 없어서 권한을 먼저 줘야 합니다
STEP 3
터미널 열기

⌘ + Space 를 눌러 Spotlight를 열고 터미널을 검색 후 엔터

💡 이후 Automator 설정이 완료되면 터미널을 다시 쓸 일은 없어요. 이번 한 번만!
STEP 4
권한 부여 명령어 실행

터미널에 아래 명령어를 복사해서 붙여넣기 후 엔터를 누르세요.

# 실행 권한 부여 chmod +x ~/Desktop/run_all.sh

아무 반응이 없으면 정상입니다. 에러가 없으면 성공!

⚠️ run_all.sh를 바탕화면이 아닌 다른 곳에 저장했다면 ~/Desktop/ 부분을 실제 경로로 바꿔주세요.

스크립트 명령어 입력

⚠️ run_all.sh 위치가 바탕화면이 아니면 경로를 맞게 수정하세요. 예: bash ~/Documents/run_all.sh

매체 추가 및 용량 제한 설정 방법
매체 추가
새로운 매체사 분류 폴더 추가하기

run_all.sh 파일을 텍스트 편집기로 열고 (우클릭 → 응용 프로그램으로 열기 → 텍스트 편집기) 7번째 줄을 찾습니다.

# 수정 전 — 기존 매체 목록 MEDIA_LIST=("Meta" "Google" "Kakao" "Naver" "Youtube" "TikTok" "Coupang") # 수정 후 — Moloco, Criteo 추가 예시 MEDIA_LIST=("Meta" "Google" "Kakao" "Naver" "Youtube" "TikTok" "Coupang" "Moloco" "Criteo")
💡 파일명에 대소문자 구분 없이 매체명이 포함되면 자동 분류돼요. 예: moloco_배너.jpg → Moloco 폴더로 이동
⚠️ 매체명을 추가한 뒤에는 반드시 저장해야 적용됩니다. 저장 후 다음 파일 감지 시점부터 새 매체가 인식돼요.
용량 제한
특정 매체 용량 압축 설정 추가하기

현재는 Kakao만 500KB 압축이 적용돼 있어요. 다른 매체에도 용량 제한을 추가하려면 스크립트 하단에 아래 블록을 복사해서 붙여넣고 폴더명과 용량만 바꾸면 됩니다.

① 파일 상단 — 용량 변수 추가

# 기존 Kakao 용량 변수 아래에 추가 KAKAO_SIZE_LIMIT=$((500 * 1024)) # 기존 500KB META_SIZE_LIMIT=$((1024 * 1024)) # 추가: Meta 1MB NAVER_SIZE_LIMIT=$((800 * 1024)) # 추가: Naver 800KB

② 파일 하단 — 압축 실행 블록 추가

아래 순서대로 따라하세요. Meta를 1MB로 압축하는 예시입니다.

1
run_all.sh 파일을 텍스트 편집기로 열기
파일 우클릭 → 응용 프로그램으로 열기 → 텍스트 편집기
2
파일 맨 마지막 줄 찾기
스크롤을 맨 아래로 내리면 echo "✅ 모든 작업 완료!" 줄이 보입니다. 바로 그 윗줄에 커서를 놓으세요.
3
아래 코드 복사 후 그 자리에 붙여넣기
코드 내용은 몰라도 돼요. 붙여넣은 뒤 Meta 와 META_SIZE_LIMIT 두 곳만 원하는 매체명으로 바꾸세요.
# Meta 폴더 용량 압축 echo "" echo "📏 Meta 용량 압축 시작..." META_FOLDER="$WATCH_FOLDER/Meta" for FILE in "$META_FOLDER"/*; do [ -f "$FILE" ] || continue FILENAME=$(basename "$FILE") [[ "$FILENAME" == .* ]] && continue case "${FILENAME##*.}" in jpg|jpeg|JPG|JPEG) FORMAT="jpeg" ;; png|PNG) FORMAT="png" ;; *) continue ;; esac FILESIZE=$(stat -f%z "$FILE") if [ "$FILESIZE" -gt "$META_SIZE_LIMIT" ]; then echo "압축 중: $FILENAME" QUALITY=85 while [ "$FILESIZE" -gt "$META_SIZE_LIMIT" ] && [ "$QUALITY" -gt 10 ]; do sips -s format $FORMAT -s formatOptions $QUALITY "$FILE" --out "$FILE" &>/dev/null FILESIZE=$(stat -f%z "$FILE") QUALITY=$((QUALITY - 10)) done echo "✅ 압축 완료: $FILENAME" else echo "✅ 용량 적합: $FILENAME" fi done
4
저장하기
⌘ + S 로 저장하면 완료!
✅ 매체를 추가할 때마다 이 4단계를 반복하면 돼요. 코드 내용은 몰라도 되고, 분홍색 Meta 와 META_SIZE_LIMIT 두 곳만 바꾸면 끝!
